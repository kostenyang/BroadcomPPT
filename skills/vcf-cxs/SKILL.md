## 簡報定位

這是 **Broadcom 原廠 Customer Success Experiences (CXS) 團隊** 的服務介紹與客戶成功案例分享簡報，
目標聽眾為公股銀行、金融保險業客戶的 IT 主管與架構團隊。核心訊息：

> 專業服務團隊助力打造【企業數位韌性】，加速數位轉型 — 專案 + 維運始終如一。

亮點數字：**百家以上成功案例、30 位原廠服務專家、服務涵蓋雲地端**。

## 推薦簡報結構 (對應原檔 27 slides)

1. **封面** — 原廠技術團隊介紹 / 客戶成功體驗部門 (CXS)
2. **Agenda** — 三大主軸 + 摘要總結
   - 【智控全局】全方位即時效能監控
   - 【擴智雲端】雲架構與微服務整合
   - 【微領全局】微服務安全合規最佳化
3. **CXS 團隊介紹** — Customer Success Experiences 部門組成、技術客戶經理 (TAM) / 資深技術顧問名單
4. **專業服務交付方法** — 完整方法論 (單一窗口管家)
   - 服務階段：業務需求訪談 → 解決方案說明 → 架構技術討論 → 細部需求確立
   - 設計：整體概念設計 → 系統邏輯設計 → 架構實體設計 → 實作內容設計
   - 建置/測試：基礎架構建置 → 解決方案建置 → 整體功能測試 → 高可用性測試
   - 知識轉移：使用情境 / 維運管理 / 監控機制 / 架構擴充
   - 交付文件：細部架構設計文件、組態工作書、測試計畫書、測試驗證報告、知識轉移與結案簡報
5. **原廠專業服務案例 — 公股金融業** — 合作銀行 / 當前服務項目 / 下一步服務策略
6. **金融保險業現代化 IT 架構** — VCF with Tanzu 成功實踐 (外匯/簡訊/壽險/網銀微服務專案)
7. **合規客製整合服務藍圖** — NSX 安全整合、特權帳號整合、Auto-Scaling、計費計量、多租戶多階層審批

### 主軸一：【智控全局】全方位即時效能監控
- 公股銀行案例一：智領未來架構三部曲 (DIY → 混合雲平台 with VCF → 雲平台最佳實踐)
- 即時監控防範未然、預防服務異常
- 智慧監控碳足跡 → 可持續虛擬化 (節能率、碳減排、電費節省)
- 儀表板智能環境監控：閒置 VM 資源回收、能效排名、快照監控、資源調整建議
- 戰情室電視牆即時監控 (JBOSS / MSSQL / 容器化平台效能監控)

### 主軸二：【擴智雲端】雲架構與微服務整合
- 公股銀行案例二：企業 IT 架構轉型，CXS 協助以 VCF with Tanzu 同步轉型
- VCF 平台核心優勢：軟體形式提供運算/儲存/網路/安全；舊三層 → 新三層 (架構層/資源層/創新層)
- 專案時程藍圖 (2024→2026 多核心專案)、資源利用率評估、預算審核採購有憑有據
- VMware Cloud 助力營運不中斷

### 主軸三：【微領全局】微服務安全合規最佳化
- 公股銀行案例三：容器環境專業化服務 (深度 × 廣度)
  - 資源管理 / 安全 / 監控告警 / 網路規劃 / 問題除錯
- 打造最安全穩定的 K8s 平台：效能蒐集、系統保護、資源自動調配、稽核日誌、RBAC 權限規劃 (單一叢集 20+ 角色)
- PSO 客製化執行架構 — 系統合規強化 + 檢核軌跡 (可搭配 Aria Automation 定期產生合規 PDF 報告)

8. **摘要總結** — 專業服務團隊助力打造企業數位韌性
   - 私有雲 SDDC 強韌架構、自動化上線符規、零信任網路微分段、雲地端災難備援、混合雲與勒索病毒復原、全方位監控戰情中心

## Key Messages

| 客戶痛點 | CXS 服務對應 |
|---------|-------------|
| 缺乏原廠專業支援 | 30+ 位原廠專家成為您團隊一部份、單一窗口管家 |
| 導入/維運斷層 | 專案 + 維運始終如一、完整知識轉移 |
| 監控被動、事後救火 | 智控全局：即時監控 + 戰情室電視牆，防範未然 |
| 微服務轉型困難 | 擴智雲端：VCF with Tanzu 平台化轉型 |
| 容器安全合規不足 | 微領全局：K8s RBAC + 稽核 + 漏洞修補 + 合規報告 |
| ESG / 永續壓力 | 碳足跡監控、節能率與資源回收 |
