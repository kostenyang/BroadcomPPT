# Tech Tuesday 範本 — 版型對照表 (layout map)

> **這份表的用途：省掉每次開檔掃 100+ 個 layout 檔的成本。**
> `slideLayoutNN.xml` 的編號是每份 deck 各自的 — 同名版型在不同範本編號完全不同，
> 所以永遠用「版型名」查這張表，不要背編號。
>
> 產生方式：`scripts/gen-layout-map.py`。範本換版時重跑一次即可。
